# Contributing

Thanks for contributing to AI Learning Assistant.

## Before opening a pull request

1. Keep changes focused and easy to review.
2. Do not commit `.env`, API keys, passwords, logs, or user uploads.
3. Run PHP syntax checks locally:
   `find . -name "*.php" -not -path "./vendor/*" -exec php -l {} \;`
4. Update documentation when behavior or deployment requirements change.
5. Use clear commit messages.

## Pull requests

Describe:
- what changed,
- why it changed,
- how you tested it,
- any environment variables or database changes required.
